# 大学生体测计算器

按《国家学生体质健康标准（2014 年修订）》计算大学生体测学年总分、等级和七项得分。输入身高（cm）与体重（kg）即可计算 BMI，性别和年级组决定适用的评分表。数据在浏览器中计算。

评分依据见[南京信息工程大学体育部的标准说明及附表](https://sport.nuist.edu.cn/tzcs1/tzjkbz1.htm)。单项按达到的最高档计分，低于最低得分档计 0 分。BMI 和学年总分保留一位小数后分别查表和评定等级。

直接用浏览器打开 `index.html` 即可使用，无需安装依赖。
